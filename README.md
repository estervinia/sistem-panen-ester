# Sistem Pencatatan Hasil Panen Digital

## Deskripsi
Sistem Pencatatan Hasil Panen Digital adalah program Python sederhana
yang digunakan untuk menghitung total hasil panen dan menghitung total
hasil setelah diberikan diskon.

## Fitur
- Menghitung total hasil panen.
- Menghitung total hasil setelah diskon.
- Menampilkan data hasil panen dalam kilogram.

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal.
2. Buka file `panen.py`.
3. Jalankan program menggunakan Python.
4. Program akan menampilkan data hasil panen, total hasil panen,
   dan total setelah diskon.

## Contoh Data
Data hasil panen yang digunakan:
- 100 kg
- 150 kg
- 200 kg
- 175 kg

Total hasil panen adalah 625 kg dan setelah diskon 10% menjadi 562.5 kg.
